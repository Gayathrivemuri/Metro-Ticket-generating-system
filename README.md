# Metro Ticket Generating System

## Project Overview
Metro Ticket Generating System is developed using ServiceNow. This application allows users to book metro tickets and generate QR-based tickets through a catalog item.

## Features
- Metro Ticket Booking
- Source and Destination Selection
- Journey Date Selection
- Ticket Count Selection
- QR Ticket Generation
- Request Management
- Data Storage in Custom Table

## Technologies Used
- ServiceNow
- Catalog Items
- Flow Designer
- UI Policies
- Custom Tables

## Project Phases
1. Ideation Phase
2. Requirements Analysis
3. Project Design Phase
4. Project Planning Phase
5. Project Development Phase
6. Project Documentation
7. Project Demonstration

## Project Outcome
The system enables users to book metro tickets efficiently and generates QR-based tickets for travel.
